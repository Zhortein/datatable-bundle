# Features

## Version 0.1 - Foundation

- Declare a datatable with a PHP class.
- Register datatables through `#[AsDatatable]`.
- Resolve datatables by name.
- Define columns through PHP definitions.
- Prepare Bootstrap-first Twig rendering.
- Prepare Ajax endpoints for columns and data.
- Prepare vanilla Stimulus integration.

## Version 0.2 - Doctrine provider

- Doctrine ORM data provider.
- Pagination.
- Single-column sorting.
- Global search.
- Doctrine metadata-based column type guessing.

## Version 0.3 - Actions

- Row actions.
- Global actions.
- Confirmation support.
- HTTP method support.
- CSRF support.

## Version 0.4 - Exports

- CSV export.
- Export current view.
- Export full dataset.
- XLSX export as optional feature.

## Later versions

- Multi-column sorting.
- Advanced filters.
- Batch actions.
- Custom data providers.
- User preferences.
- Async exports.
